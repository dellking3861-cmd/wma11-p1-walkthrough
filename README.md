# WMA11 P1 Past-Paper Concept Walkthrough

An interactive, narrated walkthrough of 13 Pearson Edexcel IAL Pure Mathematics 1 (WMA11/01) past-paper questions, with 49 concept checks and a concept report at the end. It is used alongside the student's *WMA11 Study Guide and Solved Past Papers*: each question points to the guide page where the question appears.

- Single self-contained `index.html`, no build step, no external assets.
- Narration uses the browser's built-in speech synthesis.
- Progress is saved in the browser (localStorage).

Prepared by The Classes Education System, Karachi. The walkthroughs and concept checks are the tutor's own and follow the official mark schemes. Question text is not reproduced. Not produced or endorsed by Pearson.
